# CKA Study Documents & Comprehensive Solutions

## 📌 Overview
This directory contains complete reference guides, question banks, and solutions for the **Certified Kubernetes Administrator (CKA)** exam.

---

## 📄 Files in this Directory

| File | Format | Description |
|---|:---:|---|
| `KubernetesConfiguration.pdf` / `.docx` | PDF / Word | End-to-end Kubernetes cluster configuration guide, component architecture, and installation reference. |
| `KubernetesQuestions_All_Solutions.pdf` / `.docx` | PDF / Word | Comprehensive compilation of real CKA exam practice questions, tasks, scenarios, and step-by-step verified solutions. |

---

## 🎯 How to Use These Materials
1. Review `KubernetesConfiguration.pdf` for in-depth understanding of control plane communication, kubelet mechanics, and cluster architecture.
2. Practice each scenario in `KubernetesQuestions_All_Solutions.pdf` inside your local cluster or Minikube/Kind environment.
3. Compare your command output with the practical modules in the [`Practicales/`](../Practicales/README.md) directory.
