# CKA Real-World Scenarios

## 📌 Overview
The **Scenarios** directory contains comprehensive real-world networking, infrastructure, and traffic management setups tested in advanced Kubernetes deployments and CKA troubleshooting scenarios.

---

## 📂 Subdirectories

| Scenario Module | Topic | Key Focus |
|---|---|---|
| [`CNI`](./CNI/README.md) | **Container Network Interface (CNI)** | Pod-to-Pod overlay networking, CNI plugin installation (`Weave Net`, `Calico`, `Flannel`). |
| [`Ingress`](./Ingress/README.md) | **Ingress Controllers & Routing** | NGINX Ingress Controller setup across Kind, Bare-metal/NodePort, Azure, and Cloud Load Balancers; path-based and host-based ingress routing. |
